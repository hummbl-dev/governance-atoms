# governance-atoms

Small, independently usable reference implementations of core governance primitives.

## Scope

- Kill-switch
- Simple circuit-breaker
- Basic cost governor

Each primitive is self-contained with clear interfaces. Not a full governance framework.

## Status

Public from day one under hummbl-dev.

**No GitHub Actions workflows** are included by design to conserve Actions minutes on the hummbl-dev plan. Run tests locally.

Part of the **Governance Atoms** federation. See the [federations index](https://github.com/hummbl-dev/federations) for the full list.
